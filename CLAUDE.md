# CLAUDE.md

## Agent skills

### Issue tracker

Local markdown tickets under `wayfinder/<effort>/tickets/NN-slug.md` with YAML frontmatter (no git remote). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), added to the ticket's `labels:` list. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context, with the glossary at `wayfinder/questionario-festa/CONTEXT.md` until a root `CONTEXT.md` exists. See `docs/agents/domain.md`.
